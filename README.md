# Local Notion — 서버 없는 2인 공유 폴더 위키 (시험 버전)

네트워크 드라이브에 프로젝트 폴더를 넣고 **각 직원이 `공통폴더에서_실행.bat`을 눌러 사용하는 앱**입니다. 한 사람의 PC가 꺼져 있어도 다른 직원은 계속 사용할 수 있습니다. **사내 업무에 실제 투입하기 전 테스트와 보안 정책 확인이 필요합니다.**

## 핵심 기능

- 노션 스타일 페이지 목록, 상하위 페이지, Markdown 미리보기, 제목/본문 검색
- 사진 업로드 (PNG/JPEG/GIF/WebP, 최대 20MB), 클립보드 이미지 Ctrl+V 붙여넣기, 기존 사진 참조 복사
- 공유 폴더 내 문서별 JSON 파일 저장. SQLite 및 별도 서버 불필요
- 페이지별 배타적 편집 잠금: 다른 직원이 편집 중이면 읽기만 가능
- 버전 확인 + 임시 파일을 통한 원자적 교체로 저장 (SMB 서버의 원자적 폴더 생성/파일 교체 지원 전제)
- 같은 페이지 실시간 공동 편집은 미지원

## 실행 순서

1. 회사의 프로그램 실행 및 공유 폴더 저장 정책에 맞는지 확인합니다.
2. Python 3.10 이상이 **두 직원 PC 각각**에 있어야 합니다. Python 설치가 허용되지 않는 환경에서는 별도 사내 승인된 패키징/배포가 필요합니다.
3. 저장소를 회사 네트워크 공통 폴더 (예: `Z:\\CP운영팀\\LocalNotion`)에 복사합니다.
4. 각 직원이 같은 공통 폴더에 있는 **`공통폴더에서_실행.bat`** 또는 `start.bat`을 더블클릭합니다.
5. 각자의 PC에서 `http://127.0.0.1:8765`로 접속됩니다. 다른 PC의 웹서비스에 접속하는 것이 아닙니다.
6. 페이지 열람 → **편집 시작** → 수정 → **저장**. 편집을 끝낼 때 잠금이 풀립니다.

두 사람의 드라이브 문자(Z:, Y:)가 달라도 **같은 실제 공유 폴더**를 사용하면 됩니다. 프로그램과 `shared_data` 폴더는 실제로 동일한 공유 경로를 가리켜야 합니다.

### 파일 구조

```text
LocalNotion/
├── 공통폴더에서_실행.bat
├── local_app.py
├── local_index.html
└── shared_data/             # 팀 데이터 (GitHub에 올리지 않기)
    ├── pages/              # 페이지별 JSON
    ├── images/             # 첨부 사진
    └── locks/              # 편집 잠금
```

## 중요한 운영 규칙

- 같은 페이지를 동시에 수정하려면 **첫 번째 직원이 저장/편집 종료할 때까지 두 번째 직원이 기다려야** 합니다.
- 브라우저 탭이나 로컬 Python 서버 창을 갑자기 종료하면 잠금이 남을 수 있습니다. 그 경우, 상대 직원이 실제로 편집하지 않는 것을 확인하고 해당 페이지 ID의 `shared_data/locks/<페이지ID>` 디렉터리만 제거한 뒤 다시 시도하세요. **살아 있는 편집자의 잠금은 절대 삭제하지 마세요.**
- 삭제한 페이지의 복구 기능은 아직 없으므로, 공유 폴더를 주기적으로 백업하세요. 데이터 백업은 두 직원 모두 편집을 종료한 뒤 `shared_data` 디렉터리를 회사 승인된 백업 위치에 복사하는 방식으로 시작할 수 있습니다.
- 잠금의 신뢰성은 파일 서버(SMB)의 atomic `mkdir` 동작에 의존합니다. **실제 두 PC에서 동시에 편집 시작 버튼을 누르는 경합 테스트**를 거쳐야 합니다.
- 네트워크 연결이 불안정한 경우 편집을 종료하고 연결을 확인하세요. 네트워크 공유의 캐싱, 장애, SMB 구현 차이에 따라 동시성 문제가 생길 수 있습니다.
- 웹브라우저가 열리지 않으면 'Local Notion Server' 창의 오류를 확인하세요. 포트 8765가 다른 프로그램과 충돌하면 `LOCAL_NOTION_PORT`를 변경하고 해당 주소로 접속하세요.

## 개인 페이지: 현재 미지원

**주의: 파일 기반 앱에서는 네트워크 폴더 사용자들이 원본 JSON과 이미지를 직접 읽을 수 있습니다.** 앞서 만들었던 서버 기반 개인 페이지 암호 기능은 이 파일 기반 버전에 적용되지 않습니다. 암호 입력 화면만 추가해도 보호되지 않으므로, **개인 페이지는 아직 지원하지 않으며 민감한 개인 자료를 넣지 마세요.**

향후 개인 페이지를 추가하려면 암호에서 유도한 키를 사용하는 검증된 암호화 방식으로 **페이지 본문과 첨부파일을 모두 파일 단위로 암호화**하고, 파일의 이름/메타데이터 노출과 삭제 가능성까지 고려해야 합니다. 이 기능을 검증하기 전에는 보안용으로 사용할 수 없습니다.

## 기술적 제한

- 초기 개발 MVP이며 두 대의 실제 사내 PC에서 동시 실행 테스트 **미완료**
- 편집자별 로그인 및 기록, 변경 이력/휴지통, 실시간 동기화 미지원
- 페이지 생성/이동/삭제 중 예외 처리, 네트워크 단절 복구 등의 추가 시험 필요
- 이전 서버형 소스(`app.py`, `index.html`, `서버PC에서_실행.bat`)는 이전 버전 참고용으로 남아 있으나 **새 파일 기반 모드에서는 사용하지 않습니다.**
- 프로그램 파일을 공유 폴더에서 실행할 수 있는지, IT 보안 정책상 허용되는지는 확인해야 합니다. 제한을 우회하지 마세요.

## 오프라인 단독 테스트

```powershell
$env:LOCAL_NOTION_DATA_DIR = "$PWD\\test_data"
python local_app.py
```

각 PC에서 브라우저로 `http://127.0.0.1:8765` 접속. 실제 협업 테스트에서는 같은 네트워크 공유 경로를 지정해야 합니다.

## 이미지 복사·붙여넣기

**새 이미지 붙여넣기**: 페이지에서 `편집 시작`을 누른 후 캡처 도구나 다른 앱에서 이미지를 복사합니다. 본문 편집창을 클릭하고 `Ctrl+V`를 누르면 이미지가 회사 공통 폴더 `shared_data/images`에 저장되고 본문에 표시됩니다. 저장을 눌러 반영하세요.

**기존 페이지의 이미지를 다른 페이지에서 재사용**: 첫 페이지를 **미리보기**로 열어 해당 이미지를 클릭합니다. 이미지 참조가 클립보드에 복사됩니다. 다른 페이지의 `편집 시작`을 누르고 편집창에 `Ctrl+V`한 후 저장하세요. 실제 이미지 파일을 중복 생성하지 않고 같은 파일을 참조합니다. 클립보드 접근이 제한된 브라우저에서는 이미지 참조 복사 안내창이 뜹니다.

이미지 파일의 삭제 기능은 아직 제공하지 않습니다. 다른 페이지에서 같은 이미지를 참조할 수 있기 때문에 단순히 한 페이지에서 이미지 문구를 지워도 파일은 유지됩니다.
